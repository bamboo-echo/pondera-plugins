# 论文速读卡片

## 何时使用

- 用户给出论文标题/摘要/全文，要求「这篇讲了什么、靠不靠谱」。
- 需要在多篇论文之间快速取舍。
- 要把论文结论迁移到自己项目，先判断适用边界。

不用于替代完整复现实验；不负责查重与引用格式。

## 执行步骤

1. 读摘要、引言末段、方法概览、实验表格、结论，先不看相关工作。
2. 按下表提取事实，每项只写论文明确给出的内容；缺失写「论文未给出」。
3. 区分「论文声称」与「实验支持」：声称的性能数字是否在表格里有对应行。
4. 检查对比公平性：基线是否同数据同预算、是否只报最优 seed、是否缺消融。
5. 评估可复现性：代码/数据/超参/训练细节是否公开，硬件需求是否写明。
6. 给出「值不值得精读」的判断与理由，不超过 3 条。

## 提取字段

| 字段 | 要求 |
| --- | --- |
| 研究问题 | 一句话，限定任务与场景 |
| 方法 | 核心机制 2–3 句，不含营销形容词 |
| 数据 | 数据集名称、规模、来源、划分方式 |
| 基线 | 对比对象与是否同条件 |
| 结果 | 主指标数值与提升幅度（绝对值 + 相对值） |
| 结论 | 作者主张，标注「作者观点」 |
| 局限 | 论文自述 + 你发现但论文未提的 |
| 可复现性 | 代码/数据/超参/硬件，逐项打勾 |

## 判定规则

- 主结果只在单一数据集上成立 → 标注「泛化未验证」。
- 提升幅度小于报告的标准差 → 标注「可能不显著」。
- 无消融实验 → 标注「机制贡献未隔离」。
- 基线使用了不同预算或不同预处理 → 标注「对比不公平（依据：…）」。
- 论文只给相对提升不给绝对值 → 标注「缺少绝对基线」。
- 代码未公开 → 可复现性判为「低」，但仍可精读方法部分。

## 输出格式

```markdown
## 论文速读：<标题>（<会议/年份>）

**一句话**：<问题 + 方法 + 结果>

**字段卡片**
- 研究问题：...
- 方法：...
- 数据：...
- 基线：...
- 结果：<数值>，提升 <绝对/相对>
- 作者结论：...
- 局限：...
- 可复现性：代码 ☐ 数据 ☐ 超参 ☐ 硬件 ☐

**可信度评估**
- 实验支持强度：强 / 中 / 弱（依据：<...>）
- 主要疑点：<...>

**建议**：精读 / 只读方法 / 跳过（理由 ≤3 条）
```

## 纪律

- 数字必须来自论文表格，不换算、不推测。
- 不引用二手博客的结论替代原文。
- 无法判断时写「论文未给出」，不要补全成合理猜测。
