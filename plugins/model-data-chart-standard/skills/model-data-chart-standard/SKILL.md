# 数据预处理与结果图表规范

## 何时使用

- 建模论文的「数据预处理」一节不知道写什么。
- 结果图被指出「没有误差棒」「坐标轴没单位」。
- 不清楚缺失值该删、该填还是该建模。

## 一、缺失值处理选择

| 缺失比例 | 机制 | 首选做法 | 说明 |
| --- | --- | --- | --- |
| < 5% | 完全随机（MCAR） | 成行删除 | 论文里写清删除条数与剩余样本量 |
| 5%–20% | 随机（MAR） | 中位数/众数填充，或按组内统计量填充 | 必须说明填充依据 |
| > 20% | 随机或非随机 | 插值（线性/样条）或多重插补 | 禁止简单均值填充 |
| 关键字段缺失 | 任意 | 不可填，做敏感性对比 | 说明缺失对结论的影响 |
| 时间序列缺口 | 连续缺失 | 前向填充仅限短缺口，长缺口用插值 | 标注插值区间 |

**必须写进论文**：缺失比例、机制假设、处理方法、处理前后样本量、对结果的影响。

```python
import pandas as pd

df = pd.read_csv("data.csv")
report = df.isna().mean().sort_values(ascending=False)
print(report[report > 0])

# 数值列中位数填充，类别列众数填充
num_cols = df.select_dtypes("number").columns
cat_cols = df.select_dtypes("object").columns
df[num_cols] = df[num_cols].fillna(df[num_cols].median())
for c in cat_cols:
    df[c] = df[c].fillna(df[c].mode().iloc[0])
```

## 二、异常值处理选择

1. **先判定机制**：测量错误（可删）、真实极端值（不能删）、录入错误（回溯修正）。
2. **常用判据**：IQR（`Q1-1.5IQR` / `Q3+1.5IQR`）、3σ、MAD、箱线图。
3. **处理方式**：删除并记录、截尾（winsorize）、对数变换、稳健模型（Huber/分位数回归）。
4. **禁止**：无说明地删点；为了让图「好看」删极值。

```python
q1, q3 = df["value"].quantile([0.25, 0.75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
outliers = df[(df["value"] < low) | (df["value"] > high)]
print(f"outliers={len(outliers)} bounds=({low:.2f},{high:.2f})")
```

## 三、图表类型匹配

| 数据关系 | 图型 | 避免 |
| --- | --- | --- |
| 单变量分布 | 直方图 / 箱线图 / 密度图 | 饼图展示连续量 |
| 两变量相关 | 散点图 + 拟合线 + 置信带 | 只画折线不标点 |
| 时间趋势 | 折线图（带误差带） | 用柱状图堆叠时间序列 |
| 分类对比 | 分组柱状图 / 点图 | 三维饼图 |
| 模型误差 | 残差图 / 预测-实测散点 | 只给 R² 不画残差 |
| 参数影响 | 灵敏度曲线（多参数一组） | 单点柱状图 |
| 空间/地理 | 热力图 / 等值线 | 无坐标的示意图 |

## 四、坐标轴与图元规范

- 横纵轴必须有**量名 + 单位**，如「时间 t (s)」「温度 T (°C)」。
- 中文论文用中文轴名，英文用英文；同一篇不混用。
- 刻度方向：纵轴数值增大向上；横轴按自然顺序（时间从左到右）。
- 对数轴要标 `log` 或 `10^n`，并说明取对数的原因。
- 图例放在不遮挡数据的位置；同一图内线型/标记可区分（实线/虚线/点）。
- 误差棒必须注明含义：标准差（SD）、标准误（SEM）还是置信区间（CI）。
- 拟合线给方程与 R²，参数个数与样本量同时给出。

## 五、结果表必备列

| 列 | 含义 | 示例 |
| --- | --- | --- |
| 方案/模型 | 被比较的对象 | 模型 A / B / 本文 |
| 关键参数 | 影响该结果的设置 | α=0.05、迭代 500 次 |
| 指标值 | 主指标 | 准确率 0.912 |
| 波动 | SD/SEM/CI | ±0.014 |
| 样本量 | n | 1000 |
| 相对提升 | 与基线对比 | +3.2% |
| 备注 | 异常或假设 | 剔除 12 条缺失 |

## 输出格式

```markdown
## 数据与图表规范：<课题>

### 数据预处理方案
| 字段 | 缺失比例 | 机制假设 | 处理方式 | 影响 |
| --- | --- | --- | --- | --- |

### 图表清单
| 图号 | 目的 | 图型 | 横轴(单位) | 纵轴(单位) | 误差表示 |
| --- | --- | --- | --- | --- | --- |

### 结果表模板
| 方案 | 参数 | 指标 | 波动 | n | 相对提升 | 备注 |
```

## 判定规则

- 缺失 > 20% 仍用均值填充 → 判「不合格」。
- 删异常点但未写判据与数量 → 扣分并要求补。
- 图上无单位或无误差棒 → 必须改。
- 结论图只有一条线没有对照 → 要求补基线。
- 结果表缺样本量或波动 → 视为不可复现。

## 纪律

- 所有预处理必须可复现：写清顺序（先删异常还是先填充）。
- 不虚构数据；示例值必须标明是示例。
- 图型选择给理由，不追「好看」。
