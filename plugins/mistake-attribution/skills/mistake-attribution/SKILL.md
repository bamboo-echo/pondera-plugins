# 错题归因分析

## 何时使用

- 有一批错题，想知道「到底弱在哪」而不是笼统「粗心」。
- 需要给班级或个人制定补练计划。
- 复盘一次考试，要按题型/知识点统计失分。

不负责出题（用 `quiz-generator`），也不负责重新讲整套知识。

## 执行步骤

1. **逐题记录事实**：题目、正确答案、学生答案、知识点、题型、失分。学生答案必须原样保留，不要只记「错」。
2. **归因**（五类，单选）：
   - 知识缺口：该知识点不会，无法复述定义/公式。
   - 概念混淆：知道两个概念但用错（如把「相关」当「因果」）。
   - 审题失误：漏看条件、单位、否定词、取值范围。
   - 计算失误：方法正确，运算/符号/进位出错。
   - 策略失误：时间分配、跳过、过度推导、未检查。
3. **找证据**：每条归因必须有依据（学生答案中的具体错误步骤、草稿痕迹、口头复述），没有证据的归为「待确认」。
4. **统计分布**：按知识点与归因类型交叉，找出「同一知识点反复出错」与「同一归因跨知识点出现」。
5. **给出干预**：知识缺口→补讲+变式题；概念混淆→对比表+辨析题；审题→圈画训练+限时复述题意；计算→专项慢练+验算流程；策略→限时套卷+检查清单。
6. **验证**：给出 1–2 周后的复测方式与通过标准。

## 判定规则

- 同一知识点错 3 次以上 → 判「知识缺口」，不要再归为粗心。
- 计算错误但方法正确 → 不计入知识缺口；否则会误补方向。
- 答案正确但过程错误 → 归「策略/计算」，不计为掌握。
- 题目本身有歧义或超纲 → 单列「题目问题」，不计入学生归因。
- 同一题多个错误步骤 → 归因取最早出错的那一步。
- 没有学生原始答案 → 只能做知识点层面统计，不做个体归因。

## 输出格式

```markdown
## 错题归因报告

**样本**：<n> 题　**总分失分**：<...>
**归因分布**：知识缺口 <a>｜概念混淆 <b>｜审题 <c>｜计算 <d>｜策略 <e>

### 逐题归因
| # | 知识点 | 题型 | 学生答案 | 正确答案 | 归因 | 证据 | 干预 |

### 高频问题
| 知识点/归因 | 出现次数 | 结论（真掌握 / 不稳定 / 缺口） |

### 干预计划
| 周次 | 内容 | 题量 | 通过标准 |

### 待确认
- <缺证据的条目，需要什么材料>
```

## 纪律

- 不把「粗心」当默认结论；粗心必须落到审题或计算的具体环节。
- 不虚构学生的错误步骤；没有原始作答就不做个体归因。
- 干预计划要可执行（题量、时长、判定标准），不写「加强练习」。
