# 学术论文结构大纲

## 何时使用

- 已有研究结果，但不知道按什么结构成文。
- 论文写到一半「越写越散」，需要重新收敛主线。
- 需要判断现有材料能支撑期刊论文、会议论文还是只能写技术报告。

不负责查文献、不做数据统计；引用格式另用 `citation-format-check`。

## 执行步骤

1. **锁定研究问题与贡献**：用一句话写「针对什么问题、提出什么、相对已有方法改进在哪」。贡献必须能对应到具体实验或证明。
2. **判定论文类型**：期刊论文（IMRaD）、学位论文（多章递进）、会议短文（问题+方法+结果）、建模竞赛论文（摘要+重述+假设+模型+求解+检验）。
3. **分配章节篇幅**：给出每章目标字数占比，避免「引言占一半、实验只有两段」。
4. **建立证据映射**：每个论点对应一张表或一张图；没有证据的论点标「需补实验」。
5. **规划图表**：每张图表写清「回答哪个问题、坐标轴/字段、数据来源」，同一结论不重复出图。
6. **给出写作顺序**：先方法与实验，再结果讨论，最后摘要与引言（摘要最后写）。
7. **列出待补项**：缺实验、缺对比、缺统计检验、缺复现材料。

## 结构骨架

### 期刊论文（IMRaD）

- Abstract：问题、方法、关键结果（带数字）、结论，150–250 词。
- Introduction：领域现状 → 已有方法的不足（引用支撑）→ 本文贡献列表。
- Methods：可复现到「别人照着能做」；给参数、数据划分、评价指标定义。
- Results：先主结果，再消融；每段只讲一件事。
- Discussion：解释机制、与基线差异、失败案例分析。
- Conclusion：贡献复述 + 局限 + 未来工作，不引入新结果。

### 学位论文（多章递进）

- 绪论（背景、现状、问题、贡献）
- 相关工作/理论基础
- 方法章（可按子问题拆多章，每章自成闭环）
- 实验与讨论
- 总结与展望
- 每章开头有导读、结尾有小节，章间用「承上启下」一段衔接。

### 建模竞赛论文

- 摘要（最重要，含模型、算法、结果数字、关键词）
- 问题重述（不得照抄原题）
- 模型假设与符号说明（假设要能被后文用到）
- 模型建立（每个变量有定义）
- 模型求解（算法步骤 + 结果图表）
- 灵敏度/误差分析
- 模型评价（优点、缺点、改进方向）

## 判定规则

- 贡献句无法量化或无法对应实验 → 降级为「观察」。
- 引言的「已有方法不足」没有引用 → 标「需补文献」。
- 结果章出现方法细节 → 移到 Methods。
- 同一结论出现两张图 → 合并或删一张。
- 摘要出现正文没有的数字 → 阻断，必须回溯。
- 学位论文单章超过总篇幅 40% → 检查是否该拆章。

## 输出格式

```markdown
## 论文大纲：<工作标题>

**类型**：期刊 / 学位 / 会议 / 竞赛
**一句话贡献**：<...>
**目标篇幅**：<字数或页数>

| 章节 | 目标占比 | 核心内容 | 证据（图表/实验） | 状态 |
| --- | --- | --- | --- | --- |

### 图表计划
| 编号 | 类型 | 回答的问题 | 数据来源 |

### 写作顺序
1. ...

### 待补材料
- [ ] <缺什么>（阻塞哪一章）
```

## 纪律

- 不替用户编造实验结果或文献。
- 大纲阶段不写正文；用户确认结构后再展开。
- 发现材料不足以支撑目标类型时，直接建议降级（如期刊→会议短文）。
